# Examples

> All examples are non-authoritative illustrations. They are not protocol schemas, evidence, fixtures, or a conformance corpus; `protocol.md` wins on conflict.

Examples exist to demonstrate safe command usage and workspace shape after the corresponding implementation is available. They must use synthetic identifiers and clearly fictional, non-sensitive data. They must never contain production exports, secrets, private hints, or claims presented as observed legacy facts.

An example must not fabricate `[C-COVERED]`, `[B-CONFIRMED]`, passed gates, approvals, confirmations, evidence claims, source facts, or `EXIT-E-STATUS: Passed`. If a feature is not implemented, the example must say so rather than showing fictional success output.

See [minimal/README.md](minimal/README.md) for the implemented M0 initialization and context-assembly scenario.
